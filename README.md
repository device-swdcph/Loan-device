# Dashboard ศูนย์สำรองเครื่องมือแพทย์

หน้า `index.html` แสดงจำนวนเครื่องที่พร้อมให้ยืมแยกตามประเภท โดยดึงข้อมูลสดจากแท็บ **Summary**
ของ Google Sheet "(Dashboard) ศูนย์สำรองเครื่องมือแพทย์" ผ่าน Google Visualization API
(ไม่ต้องใช้ API key) และรีเฟรชอัตโนมัติทุก 5 นาที

## ตั้งค่าครั้งแรก
1. Google Sheet → แชร์ → การเข้าถึงทั่วไป: **ทุกคนที่มีลิงก์ – ผู้มีสิทธิ์อ่าน**
2. GitHub repo → Settings → Pages → Source: *Deploy from a branch* → เลือก branch และโฟลเดอร์ `/ (root)`
3. ได้ลิงก์ `https://device-swdcph.github.io/Loan-device/`
4. Google Sites → แทรก → **ฝัง (Embed)** → แท็บ "ตาม URL" → วางลิงก์ด้านบน → เลือก "ทั้งหน้า" แล้วปรับความสูงกรอบ

## โครงสร้างแท็บ Summary ที่หน้าเว็บอ่าน
- แถวแรก: ชื่อประเภทเครื่อง (คอลัมน์ B เป็นต้นไป, คอลัมน์ "รวม" จะถูกข้าม)
- แถวที่คอลัมน์ A ขึ้นต้นด้วย "พร้อมใช้" = จำนวนเครื่องว่างให้ยืม
- แถวที่คอลัมน์ A มีคำว่า "ยืม" = จำนวนเครื่องที่ถูกยืมอยู่

เพิ่มประเภทเครื่องใหม่ได้โดยเพิ่มคอลัมน์ในแท็บ Summary ไม่ต้องแก้โค้ด
ถ้าเปลี่ยนชื่อแท็บ ให้แก้ `SHEET_NAME` ใน `index.html`

## "อัปเดตล่าสุด" ของแต่ละเครื่องมือ
การ์ดแต่ละใบแสดงเวลาที่แท็บของเครื่องนั้นถูกแก้ไขครั้งล่าสุด อ่านจากแท็บ **อัปเดตล่าสุด**
(คอลัมน์ A = ชื่อเครื่องตรงกับหัวคอลัมน์ใน Summary, คอลัมน์ B = วันเวลา)

แท็บนี้สร้างและอัปเดตอัตโนมัติด้วย Apps Script ใน `apps-script/LastUpdated.gs`
1. Google Sheet → ส่วนขยาย → Apps Script
2. ลบโค้ดเดิม วางโค้ดจาก `apps-script/LastUpdated.gs` ทั้งไฟล์ แล้วกดบันทึก
3. (ไม่บังคับ) เลือกฟังก์ชัน `stampAllNow` แล้วกด "เรียกใช้" หนึ่งครั้ง เพื่อตั้งเวลาเริ่มต้นของทุกเครื่อง
   (ครั้งแรก Google จะขอสิทธิ์ ให้กดอนุญาต)

หลังจากนั้นทุกครั้งที่มีคนแก้ไขแท็บรายเครื่อง (เช่น ชีต2) เวลาจะถูกบันทึกให้เครื่องที่สูตรใน Summary อ้างถึงแท็บนั้น
เพิ่ม/ลบเครื่องมือใน Summary ได้โดยไม่ต้องแก้สคริปต์ ถ้ายังไม่ได้ติดตั้งสคริปต์ หน้าเว็บจะซ่อนบรรทัดนี้ไว้
